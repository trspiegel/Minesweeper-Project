## 📢 &nbsp; Weekly Stand Up

Each week I will summarize my milestone activity and progress by writing a stand-up. A stand-up is meant to be a succinct update on how things are going. Use these prompts as a guide on what to write about:

⚙️ Overview - What I worked on this past week
<br>
🌵 Challenges - What problems did I have & how I'm addressing them
<br>
🏆 Accomplishments - What is something I "leveled up" on this week
<br>
🔮 Next Steps - What I plan to prioritize and do next

<br>

### Week 1

**Overview:** I chose my project, a console Minesweeper game in C++, and set up my development environment. I created a private GitHub repository, added my instructor as a collaborator, set up the required folder structure with the starter files, and moved my Visual Studio console project into the /dev folder.

**Challenges:** My repository started with a `master` branch instead of `main`. After I renamed it, every push recreated `master` on GitHub because my local branch was still tracking `origin/master`. I fixed it by fetching from GitHub, re-linking my branch with `git branch -u origin/main main`, and deleting the extra branch. The terminal also didn't recognize `git` at first, so I pointed it to the copy of Git that comes with Visual Studio.

**Accomplishments:** I leveled up my understanding of how Git connects local branches to remote branches. I now check that link with `git status` before pushing.

**Next Steps:** Create my `dev` branch and Project board, add Issues for my first features, and build the Cell and Board classes so the game board prints in the console.
